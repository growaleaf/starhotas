What this counts

"Core functions" means bindable actions from Star Citizen's own default keybind categories — flight/maneuvering, weapons, shields, power management, countermeasures, targeting, scanning, and general ship systems (docking, egress, quantum travel) — hand-counted from a current, dated community keybind mirror, not every key the game exposes. Which categories count as "core" for a given role is judged from that role's own documented ship facts: a cargo hauler's pilot really does fire its side turrets, a gunship's manned turrets are separate gunner stations the pilot never touches, an explorer's pilot seat is built around scanning rather than combat. "Slots" means physical buttons, axes, and hats on the controller (or matched pair, for a HOSAS entry), counted from the manufacturer's own product page. One physical input covers one function.

This tool reports counts and a suggested priority order (flight first, then weapons, shields, power, countermeasures, targeting, scanning, systems). It does not tell you a controller is required or sufficient for any role, or that any binding scheme is optimal — that judgment, and any modifier/shift layers your own controller software supports, is yours.
